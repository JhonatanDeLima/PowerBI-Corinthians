# ⚫⚪ Corinthians — Dashboard Temporada 2025

Dashboard interativo em Power BI para análise da temporada 2025 do Sport Club Corinthians Paulista, aplicando conceitos de Business Intelligence, modelagem de dados e visualização.

## 📊 Sobre o projeto

O painel reúne os principais indicadores de desempenho do time ao longo da temporada — Campeonato Paulista, Brasileirão, Copa do Brasil, Libertadores e Sul-Americana — com dados reais dos 74 jogos disputados no ano.

### Indicadores (KPIs)
- Total de gols marcados e sofridos
- Saldo de gols
- Aproveitamento (%)
- Jogadores que marcaram gol na temporada

### Visualizações
- 🥅 Ranking de artilheiros
- 📈 Evolução de gols marcados x sofridos por mês
- 🏆 Gols marcados por competição
- 🔴⚪ Distribuição de resultados (vitórias, empates, derrotas)
- ⭐ Destaques da temporada

## 🛠️ Tecnologias
- Power BI Desktop
- Power Query (ETL e limpeza dos dados)
- DAX (medidas e cálculos)
- Excel (base de dados estruturada)

## 📁 Estrutura dos dados
- **Jogadores** — nome, posição, gols na temporada, jogos disputados
- **Jogos** — data, adversário, competição, gols marcados/sofridos, resultado

## ▶️ Como abrir
1. Baixe o arquivo `.pbix` deste repositório
2. Abra no Power BI Desktop
3. Os dados já estão carregados no modelo — não é necessário conexão externa

## 📌 Fonte dos dados
Dados coletados de fontes públicas (Wikipédia e MeuTimão), referentes à temporada 2025 do Corinthians.
